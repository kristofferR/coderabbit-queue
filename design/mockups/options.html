Pick a structure for each page

Every option uses the same components, colours, type and wording — so these are decisions about layout, grouping, ordering and how much is visible at once, not about looks. Options marked built are what the current mockups already do. Options can also be combined; the notes at the bottom of each page say where.

Each page now shows one option at a time — the A/B/C/D chips in its top bar swap the whole variant, so you can compare like-for-like instead of scrolling past all four. The Overview goes further: its four options are built as complete pages inside overview.html itself, switchable from the same chips in the app's own top bar.
