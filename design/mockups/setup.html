Mockup notes
  • Setup doubles as an ongoing health page, so it shows a fleet mid-life, not a blank first run. A true first run would show the same sections with everything unchecked and a single “start here”.
  • The CLI section is a tool × host matrix because that’s where the real failures live: the atlas row shows installed for your shell, invisible to the service, which is the exact cause of the autofix failures on the overview — the two pages link to each other.
  • Required vs recommended is real: required tools block a daemon, recommended ones each turn on one feature and are skipped silently when missing.
  • Install commands are illustrative. The macroscope row is marked as not wired into crq preflight yet — only the CodeRabbit CLI is today.
  • Versions, paths and host names are fake data; in production they come from each host’s reported capability record (the same channel behind the “older binary” warnings).
