Mockup notes
  • Operations Desk. Frozen at Mon 2026-07-27 13:51:26 CEST; countdowns tick.
  • Layout A/B/C/D in the top bar switches the whole page — same data and same styling, four structures: stacked tables, three lanes, needs-you-only, feed-led. Each links to its tradeoffs.
  • Bot logos are the real GitHub avatars of the accounts crq matches on; repo icons are the real favicons from those repos (ha-gradient-card has none → letter-tile fallback).
  • The slide-over works: the ⚙ on any repo row (layout A) opens quick settings for that repo; × or the scrim closes it.
  • Queue rows behind the front carry a reason but never a time (matches State.Queue()); quota shows a remaining count only — the state stores no total.
