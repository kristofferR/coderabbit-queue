Mockup notes
  • The inheritance story runs both ways: each repo page says “fleet default / override”, and this page says how many repos override each default, linking to them.
  • The reviewers save is painted with its fleet impact dialog open — it names the affected repos, excludes the one that already overrides, and offers “enable it on one repo instead”.
  • Pacing rows are the real knobs (90s, 15m, 5m, 15m, 20m); retry backoff is marked hardcoded today rather than pretending it’s editable.
  • The hosts table shows the capability story that makes silent-ignore visible, including a host predating the autofix rename.
  • Plumbing is read-only on purpose: state ref, gate repo and the legacy issue are crq init’s business, not a settings form’s.
