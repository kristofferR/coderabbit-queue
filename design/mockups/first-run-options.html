First, crq needs somewhere to keep its notes

crq coordinates several machines and several bots, so it keeps one small file — which PR is being reviewed, what's queued, how much review quota is left — in a private repository of your own. You keep it; nothing leaves your account.

crq initcopy
This creates crq-home (private), a calibration pull request that measures your review quota, and the Markdown dashboard issue. Your other repositories aren't touched.

Notes on these options
  • Worth deciding first whether crq should run setup steps for you (A, B, C offer buttons) or only tell you what to run (D). That's a trust question more than a layout one.
  • C's right-hand column is reusable elsewhere — it's the same capability data the Setup page shows.
  • All four keep the promise "your other repositories aren't touched" above the fold.
